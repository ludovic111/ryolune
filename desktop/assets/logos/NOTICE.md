# Logos of other products

ryolune shows these only where it really works with the product: the plugin formats it loads
(Plugins window) and the music apps it imports songs from (first-run setup, File › Import from
Another App…). Every logo is a trademark of its owner, used only to name the product or format;
ryolune is not affiliated with or endorsed by them. Files are plain SVG paths in the owners'
colours (normalised with usvg 0.48.1), drawn on a light tile so black marks read in dark mode too.
