# ryolune 0.15.1

Plugins you can ask for, and lsuite AI. Describe the effect or instrument you want and your
agent writes it in Rust, builds it and loads it into ryolune without a restart. And if you would
rather not set anything up, sign in to lsuite AI once and the agent works.

## lsuite AI

- **No setup.** lsuite AI is the first service in Settings › Agent and in the first-run setup:
  press Sign in, sign in or create your account in the browser, press Connect ryolune, and the
  agent works. No Claude Code to install, no API key to paste.
- **One account for the suite.** Signing in from ryolune signs in every lsuite app on this
  computer (the account lives in `~/.lsuite/account.json`, readable only by you), and signing out
  signs them all out.
- **Your plan in view.** Settings › Agent shows the plan and the allowance used this month
  (`Pro · 38 % used · resets 1 Nov`), with Manage plan and Sign out.
- When this month's allowance is used up, the agent says so in one line with **Manage plan**. It
  never switches to another service on its own.
- **Claude Code can run on your plan too**: turn on Run on lsuite AI under Claude Code.
- No browser? Paste the key from your account page, or `ryolune-cli account.signIn key=lsk_…`.
- New commands: `account.status`, `account.signIn`, `account.signOut`, `account.plans`,
  `account.manage`. Agents can read the account; only you sign in or out.
- lsuite AI is a demo for now: no payment is taken. Bringing your own Claude Code, Codex, API keys
  or local models stays free and works as before.

## Plugins

- **A Plugins window** (Mix › Plugins…, ⌘⇧P) in four parts: **Stock** (ryolune's instruments and
  effects, each with what it does), **Installed** (the plugins found on this computer with the
  logo of their format, vendor and version), **Formats** (CLAP, VST3, Audio Units and lsuite
  plugins, and where ryolune looks for each), and **Build with your agent**.
- **An on/off switch on every plugin**, always in view. A plugin turned off leaves the browser and
  agents cannot load it; songs that use it still play it. lsuite plugins you installed have
  Remove.
- **Build with your agent.** Type what you want ("a bitcrusher with a mix knob") and press Build:
  the agent reads the plugin guide, starts a crate from ryolune's SDK, writes the code, builds it
  until it compiles, installs it, and loads it on your track. It says whether Rust is installed
  and how to install it.
- **No restart.** A plugin your agent builds is in the list at once; rebuild it and the tracks
  using it reload the new version.
- New commands, the same in every lsuite app: `plugin.info`, `plugin.enable`, `plugin.disable`,
  `plugin.remove`, `plugin.rescan`, `plugin.guide`, `plugin.toolchain`, `plugin.new`,
  `plugin.writeSource`, `plugin.build` (compiler errors come back as file, line and message) and
  `plugin.publishLocal`. `plugin.install` takes a plugin bundle (a folder with `plugin.toml`).
- Building and installing plugins is a permission of its own (Settings › Agent › What the agent
  can do), off until you allow it; pressing Build in the Plugins window allows it.
- Plugins build against the SDK built into ryolune, so they always match it; the crates live in
  `~/.lsuite/plugins-src/ryolune` and the installed plugins in `~/.lsuite/plugins/ryolune`.
- Two new example plugins written on the SDK: **Bitcrusher** and **Simple Chorus** (`plugins/`).

## Coming from another app

- First-run setup and File › Import from Another App… show the real logos of the apps ryolune
  brings songs from: Ableton Live, Logic Pro, FL Studio, Bitwig Studio, REAPER, Cubase, Studio One,
  Pro Tools and GarageBand.

## Smaller things

- The mark and the app icon follow kimchi's construction exactly: the ring is the same weight all
  round, and its shadow side dissolves into dither the way kimchi's leaf does.
- While nothing changes, the window no longer walks the whole song ten times a second to check
  its plugins, and waiting on the network (a sign-in, an account check) no longer redraws every
  frame: ryolune uses less power when idle.

- Plugin compiler diagnostics use portable forward-slash paths on Windows.
