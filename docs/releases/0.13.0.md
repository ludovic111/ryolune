# ryolune 0.13.0

ryolune is now Rust from the audio callback to the last pixel. The window no longer runs in a
web view: it is drawn on the GPU with GPUI, the interface framework of the Zed editor. It wears
the lsuite look shared with kimchi, and it starts working with the other apps of the
suite.

## A native window

- The window is drawn with GPUI instead of a React page inside Tauri. There is no web view and
  no JavaScript left; the app is one Rust program that draws the arrangement, the editors and
  the meters straight on the GPU.
- Everything you had is still there and works as before: the arrangement, the region editor
  (piano roll, score, step, controller lane), the inspector and the mixer, the browser, plugin
  windows and their faces, automation, the agent panel with Chat, Generate, Changes and Takes,
  the command palette, the shortcut sheet, export, recovery and Settings.
- macOS keeps its menu bar too: the same menus as the title bar, with their shortcuts.
- Every button, drag and menu in the window still runs a registry command, so `ryolune-cli`,
  `ryolune-mcp` and the agent can do everything the window does. A drag is still one undo step.

## The lsuite look

- Frosted glass for the chrome: the title bar, transport, browser, inspector and agent panel
  sit on glass over a window that blurs the desktop behind it; menus, the palette and tooltips
  are a denser glass, dialogs the densest. The arrangement, editors and mixer strips stay solid,
  so your music is never tinted.
- **ryolune teal** replaces lunar gold as the accent: the playhead, selection, focus, lit keys
  and what the agent touched. Mute, solo, record and the meters keep their own colours.
- Dark and light, both checked for contrast on every surface and every glass tier, over the
  brightest and the darkest desktop. With Reduce transparency on, the glass turns opaque.
- Manrope and IBM Plex Mono, as before, now bundled inside the app.
- A new app icon from the lsuite template: a teal squircle with the ring and the dot.

## Working with the suite

- ryolune writes `~/.lsuite/apps/ryolune.json` when it starts: its version, where its CLI and MCP
  server are, and while it runs its bridge port. Nothing secret goes in it. `app.suite` lists the
  lsuite apps installed on the computer.
- **To kimchi**: `export.toKimchi` renders the mix, or one stem per track, for a kimchi video
  project. With kimchi open, kimchi puts it on its open project itself, in its own undo history;
  with kimchi closed, it lands on new audio tracks of the project you name.
- **From kimchi**: a cut sent with kimchi's "Send the cut to ryolune to score" (its audio,
  length and markers) arrives straight in the open song, or waits in
  `~/.lsuite/handoff/ryolune` for `session.scoreCut`: the audio on a new track, each marker on
  the ruler where it falls, the cycle over the cut. `handoff.inbox` lists cuts waiting for ryolune.
- The names every lsuite app shares work here too: `app.version`, `project.overview`,
  `export.audio`, `export.stems` and `export.midi`.

## Details

- The region editor shares the height with the arrangement on smaller windows.
- The Channel EQ in the inspector draws the real curve of the track's EQ.
- The mixer shows the A and B returns beside the Stereo Out.
- Score view draws notes an octave lower than before, where they belong (E4 on the bottom line).
- Musical typing leaves text fields alone.
- Fixed: opening an Audio Unit's own window could stop a debug build.
- Tests can no longer write to your settings, data folder or lsuite folder, even when run
  without their scratch variables.

## For developers

- `desktop/src/ui` is the window (see its `README.md`); `frontend/`, Tauri and Node are gone.
  Building needs Rust only. Linux needs GPUI's libraries (xkbcommon, Wayland/X11, fontconfig,
  Vulkan) instead of WebKitGTK.
- MIDI input uses midir 0.10: GPUI pins core-foundation 0.10.0, which midir 0.11 cannot share.
- `docs/SHORTCUTS.md` is generated from the window's shortcut sheet
  (`RYOLUNE_BLESS=1 cargo test -p ryolune shortcuts`).
