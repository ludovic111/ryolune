# Ondera 0.7.0

## Recording
- Count-in before a take (Settings > Audio > Count In Bars, default one bar). The song stays parked
  while the click runs and starts on the sample; the microphone opens during the count, so the
  start of a take is no longer lost.
- Microphone level meter on armed audio tracks, before and during a take.

## Plugins
- The browser files every plugin (stock, native, CLAP, VST3, AU) in colour-coded sound folders, with
  Favourites, Recent, a star on each row and right-click re-filing, including folders of your own.
- Ten new stock plugins: Tonewheel Organ, String Ensemble, Analog Bass, Flanger, Auto Pan,
  Auto Filter, De-Esser, Lo-Fi, Pitch Shift and Pump. Stock front panels wear their family colour.
- Native Rust plugins: panics are contained instead of aborting the app, `ondera_plugin::testing::Bench`
  tests a plugin through the real ABI, `plugin.scaffold` starts a new plugin crate and
  `plugin.install` installs a built one. ABI stays at 1.

## Files
- Imports AIFC, CAF, MP2, M4B/MP4, OGA, MKA/MKV/WebM as well; surround files are downmixed to
  stereo; a MIDI file can be dropped on the window. Exports AIFF (16/24-bit) as well as WAV.

## CLI, MCP and agent
- 150 commands. New: `session.batch` (many commands, one request, one undo step, atomic),
  `clip.trim`, `clip.deselect`, `source.peaks`, `transport.punch`, `note.hold`, `note.releaseAll`,
  `app.confirm`, `app.relaunch`, `session.saveRecoveredTake`, `ui.closePluginWindow`,
  `ui.dismissError`, `agent.changes`, `agent.revert`, `plugin.folders`, `plugin.setFavorite`,
  `plugin.setFolder`, `plugin.scaffold`, `plugin.install`. `ui.status` reports pending prompts.
- Control requests are answered between window ticks: about 0.75 ms each instead of up to 33 ms.
- Agent panel: what the agent did in plain words, the selection sent as context, and Ask Agent
  About Selection (Shift-Cmd-J and the region, lane and track menus).

## Interface and performance
- Per-theme motion for menus, dialogs, panels and controls; respects reduced motion.
- Fader and dial drags send only their newest value and fetch one snapshot; waveforms draw from a
  max-pyramid; meters re-render only when a segment changes; the idle window no longer
  re-serialises the agent transcript ten times a second.

## Known limits
- No input monitoring yet: you cannot hear the microphone through Ondera while recording.
- The count-in and input meter were verified in the live window with MIDI; record one real
  microphone take after installing to confirm them on your interface.
- Export is WAV and AIFF. FLAC and MP3 are not built.
- Native Rust plugins still persist parameters only, and receive note on/off only (ABI 1).
- A few window actions have no command yet: see `docs/AGENT_PARITY.md`.
